# Cómo usar tu nueva configuración de Open Code 🚀

¡Felicidades! Ahora tienes una de las configuraciones más avanzadas para Open Code. Aquí tienes cómo sacarle provecho a cada archivo que hemos creado:

## 1. Configuración Global (`opencode.jsonc`)
Tu asistente ahora tiene "superpoderes" automáticos:
- **n8n**: Puede consultar tus flujos de trabajo de automatización.
- **NotebookLM**: Puede investigar en tus cuadernos sin que tengas que copiar y pegar.

## 2. Skill de Diseño (`.open-code/skills/frontend-design.skill.md`)
Cuando quieras mejorar la apariencia de algo, dile:
> *"Aplica la skill de frontend-design a la página de [nombre de la página]."*
O simplemente:
> *"Mejora el diseño de este componente siguiendo mis estándares de diseño."*

## 3. Sistema Multi-Agente (`agents.md`)
Open Code leerá este archivo automáticamente cada vez que inicies una tarea. 
- No tienes que hacer nada extra; el agente ya sabe que debe actuar como **Arquitecto** al planear y como **Constructor** al programar, siguiendo las reglas de Next.js y Supabase que definimos.

## 4. Servidor LSP
Al trabajar en archivos `.tsx` o `.ts`, verás que el agente es mucho más preciso detectando errores antes de que tú los veas. Esto es gracias al protocolo de lenguaje que hemos optimizado.

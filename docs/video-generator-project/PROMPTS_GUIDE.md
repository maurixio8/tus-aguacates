# Guía de Prompts para Imágenes - Tus Aguacates

## Estilo Visual de Marca

### Colores de Referencia
```
Verde Bosque (principal): #2D5016
Verde Aguacate: #6B8E23
Dorado (acentos): #D4AF37
Crema (fondos claros): #FFFEF5
Tierra (madera): #D4AF85
```

### Elementos Visuales Clave
- **Marco/Frame**: Borde dorado elegante (8-12px)
- **Fondo**: Degradado verde oscuro o superficie de madera
- **Iluminación**: Cálida, natural, desde arriba-izquierda
- **Perspectiva**: POV (primera persona) o cenital (desde arriba)
- **Estilo**: Fotografía gastronómica profesional, minimalista, premium

---

## Estructura del Prompt

### Fórmula Base
```
[ESTILO] + [PERSPECTIVA] + [ACCIÓN/SUJETO] + [ESCENARIO] + [ILUMINACIÓN] + [DETALLES DE MARCA] + [FORMATO]
```

## MODIFICADORES ÚTILES

### Para más realismo
```
+ photorealistic, hyperrealistic, 8K UHD, RAW photo
+ shot on Canon EOS R5, 85mm lens, f/2.8
+ natural skin texture on hands
+ visible food texture and moisture
```

### Para estilo más artístico
```
+ soft dreamy atmosphere
+ golden hour magic light
+ ethereal glow
+ painterly quality while maintaining realism
```

### Para más dinamismo
```
+ motion blur on action elements
+ ingredients floating mid-air
+ splash of liquid captured
+ steam rising from food
```

### Para consistencia de marca
```
+ dark green color palette #2D5016
+ golden accent details #D4AF37
+ elegant minimalist composition
+ premium luxury food aesthetic
+ subtle sparkle effects
```

## NEGATIVOS (Qué evitar)

Añadir al final del prompt:
```
Negative prompt: cartoon, illustration, drawing, painting,
blurry, low quality, oversaturated, plastic looking food,
artificial lighting, cluttered background,
messy presentation, unappetizing, raw meat visible,
faces, full body shots, text, watermarks, logos
```

## WORKFLOW RECOMENDADO

1. **Generar 4 variaciones** de cada imagen
2. **Seleccionar la mejor** que cumpla con el estilo
3. **Upscale** si es necesario (para 4K/8K)
4. **Post-procesar** en Photoshop/Canva si necesita ajustes menores
5. **Agregar frame dorado** si no se generó bien (template en Canva)
6. **Exportar** en los dos formatos (vertical y horizontal)
